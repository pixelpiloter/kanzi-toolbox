# kanzi工程间拷贝节点思路

> 原文: https://blog.csdn.net/chen_227/article/details/138219576  
> 发布: 2024-04-26  

背景:kanzi studio之间是不可以数据互通的,想要从一个工程复制节点到一个工程,只能用 Import Project|Merge Project ,有时候不太方便。

[IMG]

期望的效果

工程A下任意节点或资源,右键选择 MyCopy ,复制数据到剪贴板,在工程B下右键父节点,选择 MyParse ,能够快速把节点数据复制过来。

[IMG]

设计

主题框架采用【Kanzi Studio 命令插件】,开发语言C#。

[IMG]

[IMG]

每次生成dll都需要拷贝到 C:\ProgramData\Rightware\Kanzi 3.6.10\plugins 目录,并重启kanzi studio。

复制

因为 ProjectItem 没法序列化,需要手动把节点数据序列化。

```
enum MyEnum
{
MyEnum_ProjPath = 0,
MyEnum_KzUrl,
MyEnum_TypeDisplayName,
MyEnum_Name
};

string output = "";
output &#43;= studio.ActiveProject.FileSystemPath &#43; "\n";
output &#43;= item.KzbUrl &#43; "\n";
output &#43;= item.TypeDisplayName &#43; "\n";
output &#43;= item.Name;
Clipboard.SetText(output);

```

代码用于demo测试,实际需要递归序列化节点和子节点,输出格式xml,并复制到剪贴板。

粘贴

因为 ProjectItem 没法反序列化,需要手动把节点数据反序列化。

```
enum MyEnum
{
MyEnum_ProjPath = 0,
MyEnum_KzUrl,
MyEnum_TypeDisplayName,
MyEnum_Name
};

string str = Clipboard.GetText();
var datas = str.Split('\n');
var Name = datas[(int)MyEnum.MyEnum_Name];
var TypeDisplayName = datas[(int)MyEnum.MyEnum_TypeDisplayName];
if (TypeDisplayName is "Text Block 2D")
{
var item = studio.ActiveProject.CreateProjectItem<TextBlock2D>(item_parent.GenerateUniqueChildName(Name), item_parent);
}
else if (TypeDisplayName is "Image")
{
var item = studio.ActiveProject.CreateProjectItem<Image2D>(item_parent.GenerateUniqueChildName(Name), item_parent);
}

```

代码用于demo测试,实际需要递归反序列化节点和子节点,并创建节点。
